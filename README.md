# Вестник адекватности — цифровой сад

Личный сайт-сад: заметки о работе с людьми, обучении, культуре и заботе.
Статика без фреймворков: чистый HTML, CSS и немного JS.

**Живёт:** https://nsbshal-arch.github.io/sad/

## Как устроено

```
index.html      главная (сад)
notes.html      список заметок + теги
about.html      обо мне
now.html        страница «сейчас»
notes/*.html    заметки
style.css       вся вёрстка и темы (светлая/тёмная)
script.js       переключатель темы + прогресс чтения
rss.xml         лента
sitemap.xml     карта сайта
_build/build.py сборщик страниц
```

## Как добавить заметку

1. Открой `_build/build.py`, найди список `NOTES`.
2. Скопируй любой блок и поменяй:
   - `slug` — адрес файла (`notes/<slug>.html`)
   - `title`, `excerpt`, `date` (ГГГГ-ММ-ДД)
   - `status` — `seed` (росток), `draft` (черновик) или `ever` (зрелая)
   - `tags` — список тегов
   - `related` — slug'и связанных заметок
   - `body` — HTML текста (`<h2>`, `<p>`, `<ul>`, `<blockquote>`)
3. Запусти сборку:

```
python3 _build/build.py
```

Сборщик сам обновит главную, список, заметку, RSS и sitemap.

## Публикация

```
git add -A
git commit -m "новая заметка"
git push
```

GitHub Pages обновится сам через минуту-две.
